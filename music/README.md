# music/

Drop audio files in this folder and they appear in Pulse under
**Settings → Cloud library (my GitHub folder)**.

- Supported: mp3, m4a, aac, flac, ogg, opus, wav
- Subfolders work (up to two levels deep), so `music/sets/` is fine
- On the phone: Cloud library lists what is here, marks what you already have,
  and downloads the new ones into the app so they play offline
- Tags, artwork, duration and BPM are read from each file on download

Two practical limits from GitHub: a single file must be under 100 MB, and the
whole repository should stay under about 1 GB.

**This repository is public.** Only put audio here that you are free to
distribute — your own recordings and mixes, royalty-free material, or things
released for free sharing. Commercial albums do not belong in a public repo.

`demo-test-beat-128bpm.mp3` is a synthetic 128 BPM test tone generated for
checking the pipeline. Delete it whenever you like.
